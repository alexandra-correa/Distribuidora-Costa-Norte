# Distribuidora Costa Norte

Sitio web de Distribuidora Costa Norte, orientado a presentar su catálogo de productos y facilitar el contacto con sus clientes.

## Características

- Catálogo visual de productos.
- Categorías para explorar distintas líneas de productos.
- Imágenes de productos y categorías.
- Diseño visual con la identidad de la distribuidora.
- Información de contacto y acceso a Instagram.

## Tecnologías

- HTML5
- CSS3
- JavaScript
